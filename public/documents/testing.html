Testing

Verified Last updated: September 2026

AquaDealers has two test layers: unit tests via Vitest and end-to-end tests via Playwright.

Unit Tests (Vitest)

Configuration

  • Config file: vitest.config.ts
  • Environment: jsdom
  • Libraries: @testing-library/react, jest-dom
  • Run command: npm test

E2E Tests (Playwright)

Configuration

  • Config file: playwright.config.ts
  • Browser: Chromium only
  • Credentials: Test dealer account via .env.e2e file
  • Run command: npm run test:e2e

Test Specs (5)

1. billing.spec.ts — Full Bill Creation

End-to-end bill creation flow:

  • Log in as test dealer
  • Navigate to New Bill
  • Select a farmer
  • Add products to cart
  • Set quantities and review totals
  • Choose payment method
  • Complete checkout
  • Verify bill appears in bill list

2. farmer-payment.spec.ts — Payment Collection

Payment recording flow:

  • Log in as test dealer
  • Navigate to a farmer with outstanding balance
  • Record a payment (cash or digital)
  • Verify balance updates
  • Verify payment appears in farmer ledger

3. stock-purchase.spec.ts — Stock Purchase

Inventory purchase flow:

  • Log in as test dealer
  • Navigate to Stock Purchase
  • Select supplier and products
  • Enter quantities, prices, and batch details
  • Complete purchase
  • Verify stock levels update

4. auth.spec.ts — Authentication Flows

Authentication flow tests:

  • Redirect unauthenticated users to login
  • Admin login page rendering

5. screenshot.spec.ts — Login/Register Screenshots

Utility spec that captures screenshots of the login and register pages for visual reference.

Support Files

  • tests/e2e/auth.setup.ts — Authentication setup (logs in before tests)
  • tests/e2e/fixtures.ts — Shared test fixtures
  • tests/e2e/helpers/db.ts — Database helper for test setup/teardown

Running Tests

Commands

# Unit tests (Vitest)
npm test

# Unit tests in watch mode
npm test -- --watch

# E2E tests (Playwright)
npm run test:e2e

# E2E tests with UI mode
npx playwright test --ui

# E2E tests for a specific spec
npx playwright test billing.spec.ts

E2E Prerequisites

Before running E2E tests:
  • Create a .env.e2e file with test dealer credentials
  • Ensure the dev server is running (npm run dev)
  • Install Playwright browsers: npx playwright install chromium
  • The test dealer account must have existing data (farmers, products, stock) for the tests to pass
