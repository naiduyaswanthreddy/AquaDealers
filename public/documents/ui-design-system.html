Branch Theming

Each branch gets a color_theme value stored in the branches table. The theme color is applied to the sidebar accent, active/selected states, and branch indicator badges throughout the UI.

Typography

  • Primary: Plus Jakarta Sans (weights: 400, 500, 600, 700, 800)
  • Fallback: Noto Sans for regional scripts
  • System stack fallback: system-ui, sans-serif
  • Monospace: JetBrains Mono (code blocks, technical displays only — not used in app UI)
  • Base size: 15px
  • Line height: 1.65

Notifications

  • Library: sonner
  • Position: top-center
  • richColors enabled, closeButton enabled
  • Used across 60 files for success/error/info feedback
  • Pattern: toast.success("Bill created"), toast.error("Failed to save")

Icons

  • Library: lucide-react
  • Standard sizes: 20px (default), 16px (inline/small)
  • Stroke width: 2 (consistent across all icons)
  • Color inherits from parent text color

Dark Mode

Not supported. Dark mode is not supported. The app uses color-scheme: light hardcoded in the HTML root. All color tokens assume a light background.
