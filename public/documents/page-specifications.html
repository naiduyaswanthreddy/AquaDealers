1. Dashboard

PropertyValue
Route/dashboard
AccessAuthenticated dealer or staff with dashboard: "visible"
Feature gateNone

KPI StatCards (5)

Displayed in a horizontal row at the top. Each card shows a primary metric value, label, and comparison to the previous period.

  1. Today's Sales — total billing amount for today
  2. Today's Collections — total payments received today
  3. Total Outstanding — sum of all farmer dues
  4. Bills Today — count of bills created today
  5. Active Farmers — farmers with at least one bill in the last 90 days

Toggleable Widgets (10)

Each widget can be shown/hidden via a gear icon. State persisted in dealer preferences.

  1. Sales Trend — line chart of daily sales for last 30 days (Recharts)
  2. Top Products — bar chart of top-selling products by quantity
  3. Overdue Farmers — list of farmers with overdue payments, sorted by amount
  4. Recent Bills — last 5 bills with farmer name, amount, status
  5. Low Stock — products below reorder point
  6. Expiring Stock — lots expiring within 30 days
  7. Payment Methods — pie chart breakdown (cash/UPI/bank/cheque)
  8. Branch Comparison — sales comparison across branches (if multi-branch)
  9. Monthly Summary — month-to-date sales, collections, purchases
  10. Quick Actions — shortcut buttons for common actions

Layout

  • Desktop: KPI cards in a single row. Widgets in a 2-column grid below.
  • Mobile: KPI cards as a horizontal scroll. Widgets stack vertically.

2. New Bill

PropertyValue
Route/bills/new
AccessAuthenticated dealer or staff with newBill: "visible"
Feature gateNone
Key componentProductSelector (~1,600 lines)

Mobile Layout (3 Steps)

1
FarmerSelector — Search/select farmer. QuickAddFarmerModal for inline creation.
2
ProductSelector — Full-screen product grid. Search, category filter. Tap product to add. Quantity/rate inline editing. Running total shown.
3
PaymentStep + ReviewStep — Payment amount, method. Bill summary. Signature canvas. Save button.

Desktop Layout (2 Panels)

  • Left panel: Farmer search at top, product catalog below (Feed/Medicine tabs). Grid card columns are responsive: 2 columns below 1300px wide, 3 columns at 1300px and up, so cards never get squeezed at moderate desktop widths.
  • Right panel: Selected items table, then a collapsible Payment Details card, then the total/action bar.

Payment Details Card (Desktop)

Starts collapsed by default, showing just the paid/balance-due amount. Clicking the header (or its chevron) expands it into two columns: left — payment method, amount received, settlement discount (editable); right — a read-only Bill Summary (subtotal, item discount, GST, settlement discount, total, paid, balance due).

The bottom-right action button reflects this state: while the card is collapsed it reads "Payment" and clicking it only opens the card (doesn't submit). Once the card is open — whether opened via that button or by clicking the header directly — the same button becomes "Review & Sign" and proceeds to the review step.

Draft Tabs

Up to 5 concurrent drafts stored in sessionStorage. Tab bar at top of billing page. Each draft preserves: selected farmer, added products with quantities, and payment info. Allows switching between partial bills when interrupted.

Keyboard Shortcuts

ShortcutAction
/Focus product search
EscClose modal / clear search
EnterConfirm quantity / advance step
TabMove between quantity fields

Empty State

If no products are configured yet, shows a prompt to "Add your first product" with a link to inventory setup.

3. Farmer Ledger

PropertyValue
Route/farmers/:id (one page, tabs are client-side state — no sub-routes per tab)
AccessAuthenticated dealer or staff with farmerList visible
Data sourceLedger tab: paginated get_farmer_ledger_page RPC with infinite scroll. Bills/Payments tabs: paginated direct table queries.

Tabs

  • Ledger — Chronological list of all transactions (bills, payments, returns, adjustments). Infinite scroll with paginated RPC. Each entry shows date, type, amount, running balance. Since 2026-09-17: clicking a return entry opens a read-only breakdown of its items and amount (see Returns); bill entries navigate to Bill Details; payment entries are not clickable.
  • Items — Products purchased by this farmer with quantities and totals, net of any returns (see Returns).
  • Bills — Paginated list of this farmer's bills. Since 2026-09-17: any bill with a return against it (either return flow) shows an orange "Return" badge next to its item list.
  • Payments — Paginated list of payments received from this farmer.
  • Details (mobile only, folds into the sidebar on desktop) — Contact/farm/financial info, edit access.

Per-product discount rates (FarmerProductDiscounts) render as a standalone section near the top of the page, not as a tab — gated behind the farmer_product_discounts subscription feature and the dealer's own toggle for it.

Actions

  • Collect Payment (opens payment flow with farmer pre-selected)
  • Create Bill (opens billing with farmer pre-selected)
  • Share Statement (WhatsApp or PDF)
  • View Statement (formatted printable view)
  • Edit Farmer (profile details)

Layout

  • Desktop: Farmer summary card at top (name, phone, outstanding, credit limit). Tabs below with full-width table; Details folds into a sidebar instead of its own tab.
  • Mobile: Farmer summary as compact header. Tabs as swipeable. Ledger/Bills/Payments entries as cards instead of table rows.

4. Farmer List

PropertyValue
Route/farmers
AccessAuthenticated dealer or staff with farmerList: "visible"

Searchable, filterable list of all farmers. Search by name or phone number. Filter by: outstanding balance range, last bill date, active/inactive status. Sort by: name, outstanding amount, last activity. Pagination: server-side with page size of 20.

Empty state: "No farmers yet. Add your first farmer to get started" with an "Add Farmer" button.

5. Inventory

PropertyValue
Route/inventory
AccessAuthenticated dealer or staff with inventory: "visible"

Product list with current stock levels. Each row shows: product name, category, current stock quantity, unit, latest rate, total stock value. Search by product name. Filter by category, stock status (in stock, low stock, out of stock). Color-coded stock indicators: green (adequate), yellow (low), red (out of stock).

6. Inventory Detail

PropertyValue
Route/inventory/:id
AccessAuthenticated dealer or staff with inventory: "visible"
Component size1,444 lines

Sections

  • Product Summary: Name, category, current stock, average cost, latest selling rate, MRP
  • Active Lots: Table of FIFO lots — purchase date, quantity remaining, cost per unit, expiry date, supplier. Sorted oldest first.
  • Movement History: All stock movements for this product — purchases, sales, returns, transfers, adjustments. Filterable by type and date range.
  • Rate Adjustment: Change selling rate per lot with reason tracking. Creates audit entry in movements.

Actions

  • Record Purchase (opens purchase form pre-filled with this product)
  • Adjust Rate (change selling rate with reason)
  • Stock Adjustment (manual correction with reason)
  • View by Branch (if multi-branch, toggle stock view per branch)

7. Reports

PropertyValue
Route/reports and /reports/:section
AccessAuthenticated dealer or staff with reports: "visible"

Date Presets

All reports support: Today, Yesterday, This Week, This Month, Last Month, This Quarter, This Year, Custom Range.

Report Sections

  • Sales Register — Every bill with line items, grouped by date
  • Profit Report — Revenue minus cost of goods sold, per product
  • Stock Report — Current stock levels, valuation, expiring items
  • Dues Report — Farmer-wise outstanding with ageing
  • Collection Report — Payments received, grouped by method
  • Purchase Report — Supplier-wise purchases
  • GST Report — Tax breakdown for filing

Export Formats

PDF (via jsPDF) and Excel-compatible CSV. Reports open in a printable view for direct browser printing.

8. Daily Book

PropertyValue
Route/daily-book and /daily-book/:section
AccessAuthenticated dealer
StyleRegister-style daily view

Sub-pages (11)

  1. Summary — Day overview with totals for all categories
  2. Bills — All bills created on the selected date
  3. Payments — All payments received
  4. Purchases — All stock purchases
  5. Supplier Payments — Payments made to suppliers
  6. Returns — All returns processed
  7. Expenses — All expenses recorded
  8. Cash Entries — Manual cash book entries
  9. Stock Transfers — Inter-branch transfers
  10. Adjustments — Stock and rate adjustments
  11. Cancellations — Cancelled bills

Key Behaviors

  • Date navigation: Left/right arrows to move between days. Date picker for jumping to specific date.
  • Prefetching: Adjacent days (yesterday and tomorrow) are prefetched for instant navigation.
  • Empty state: "No activity on this date" with option to navigate to nearest active date.

10. Dues

PropertyValue
Route/dues
AccessAuthenticated dealer

Ageing Buckets

Farmers grouped by how long their dues have been outstanding:

  • 0–30 days — Current dues (normal)
  • 31–60 days — Overdue (yellow)
  • 61–90 days — Significantly overdue (orange)
  • 90+ days — Critical (red)

Key Behaviors

  • Virtualized list: Uses windowed rendering for performance with 500+ farmers
  • Click farmer to open ledger
  • "Collect Payment" action per farmer row
  • "Send Reminder" via WhatsApp per farmer
  • Sort by: amount, name, age of oldest due
  • Summary card at top: total outstanding, number of farmers with dues

14. Bill History

PropertyValue
Route/bills
AccessAuthenticated dealer or staff with billHistory visible

Searchable list of bills for the active branch (or all branches, in "All Branches" mode). Search by bill number or farmer name. Filters: date range, verified status (all/verified/unverified), payment status (all/paid/unpaid). Sort is fixed to newest-first (created_at desc); page size is a 10/25/50 selector with a "Load more" button (offset-based server pagination via billingService.getBills(), not a cursor). A "Show Items" toggle swaps the Type/Payment/Verified/Notification columns for an inline item list per row.

Each row: bill date, bill number, farmer/customer name (with a branch badge and, since 2026-09-17, an orange Return badge if any return — bill-first or farmer-first — touched this bill), type (Estimate/Credit/Cash), payment status, verified status, WhatsApp notification status (if the WhatsApp add-on is on), and total amount. KPI cards above the table (desktop only) show total bills/amount/paid/pending for the selected range vs. the prior period.

15. Bill Detail

PropertyValue
Route/bills/:id
AccessAuthenticated dealer or staff with billHistory or newBill visible (there is no separate returns feature key — the Return action and /returns route are both gated by billHistory)

Display

Renders the bill using the configured invoice template (TemplateOne through TemplateFive). Shows: bill number, date, farmer details, line items with quantities/rates/amounts, subtotal, discounts, GST breakdown (if applicable), total, payment received, balance due, signature (if captured).

If the bill has any returns against it (see Returns): an orange "Return Filed · ₹X" badge appears next to the branch badge right under the bill number — click it to jump straight to the returns list further down the page, no scrolling blind. Any line item that was partially or fully returned shows the net remaining quantity with a small "N sold − M returned" note underneath it (summed across both return flows). A Returns on this bill card near the bottom of the page lists every return tied to this bill with its own returned items, amount, and date.

Actions

  • Edit — Opens the inline EditBillModal. Gated on the Pro+ plan (dealer.plan === 'pro_plus') or the custom_templates feature flag.
  • Cancel — Same-day only, unpaid only. Confirmation dialog. Calls cancel_bill_v1 RPC.
  • Return — Navigates to /returns pre-filled with this bill's farmer and items (the farmer-first return flow; see Returns).
  • Share via WhatsApp — Sends bill notification via authkey.io or opens wa.me link.
  • Download PDF — Renders bill to PDF via html2canvas (DOM → canvas → PNG → PDF).
  • Print — Opens browser print dialog with the invoice template.
  • Collect Payment — If balance due > 0, opens payment flow pre-filled with this bill's farmer and remaining amount.
