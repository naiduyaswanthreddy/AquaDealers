Completed Features

All features below are live in production as of AquaDealers v3.0.0.

Core Billing & Inventory

  • ✓ Core billing with FIFO lot tracking
  • ✓ Estimates and returns
  • ✓ Bill editing with audit trail
  • ✓ Bill cancellation (same-day)
  • ✓ Per-farmer product discounts and rate memory
  • ✓ GST billing (per-item rates, CGST/SGST)
  • ✓ Rate adjustment history
  • ✓ Expiry management
  • ✓ Low stock alerts
  • ✓ Transaction undo (48h window)

Farmer & Supplier Management

  • ✓ Farmer management with paginated ledger
  • ✓ Public farmer statement sharing
  • ✓ Supplier management with ledger

Multi-branch & Staff

  • ✓ Multi-branch with stock transfers
  • ✓ Staff access with PIN auth
  • ✓ Admin portal with impersonation
  • ✓ Branch color theming

Financials & Reports

  • ✓ Cash book with daily closing
  • ✓ Expense tracking
  • ✓ Daily Book register
  • ✓ Monthly finance pack
  • ✓ Profit report (FIFO-based COGS)
  • ✓ Sales register
  • ✓ Stock report with valuation

Communication & Platform

  • ✓ WhatsApp API bill notifications
  • ✓ Offline-first PWA billing
  • ✓ Invoice template customization (5 designs)
